Mobile menu styles extension for WordPress Navigation block.

== Description ==

Adds mobile menu style options to the WordPress Navigation block. Configure different menu animations and positions directly in the block inspector.

= Features =

* Left Drawer - Slide in from left
* Right Drawer - Slide in from right
* Top Dropdown - Slide down from top
* Bottom Popup - Slide up from bottom
* Fullscreen Overlay - Full screen overlay

= Usage =

1. Add a Navigation block to your page
2. Select the Navigation block
3. In the block inspector (sidebar), find "Mobile Menu" panel
4. Choose your desired menu style
5. Configure additional options (width, overlay, speed, breakpoint)
